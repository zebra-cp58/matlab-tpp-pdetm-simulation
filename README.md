# MATLAB Simulation for Prescribed-Time Bipartite Consensus Control

This repository contains the MATLAB simulation code for the paper:

**"Prescribed-Time Bipartite Consensus Control of Multi-Agent Systems With Enhanced Transient Performance Guarantees"**
*Guangsheng Fang, Ao Luo, Hui Ma, Mali Xing, Qi Zhou*
Published in *Journal of Automation and Intelligence* (2026).

## 📁 File Structure
- `try63.m`: Main script for parameter initialization, simulation execution, and plotting.
- `tryhan63.m`: The system dynamics and controller function used by the `ode15s` solver.

## 🚀 How to Run
1. Place both `.m` files in the same directory.
2. Open MATLAB and run `try63.m`. 
3. The script will simulate the multi-agent system and generate figures.

## 🛠️ Requirements
- MATLAB (Recommended R2020b or later)
